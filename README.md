# 豆瓣收藏高级搜索（油猴脚本）

在豆瓣 **音乐 / 电影 / 读书** 的个人收藏页（听过 / 看过 / 读过 等）右侧栏注入高级搜索面板，跨**全部收藏**按
**作品名 / 表演者·作者·导演 / 年份 / 标签 / 我的评分 / 标记日期** 精确检索——豆瓣官方收藏页只有按时间/评分/标题排序和单标签筛选，没有字段级搜索。

支持站点与页面：

| 站点 | 页面 | 状态词 | 表演者字段 | 标签 |
|---|---|---|---|---|
| `music.douban.com` | `/people/<ID>/collect·wish·do` | 听过 / 想听 / 在听 | 表演者 | ✅ |
| `movie.douban.com` | `/people/<ID>/collect·wish·do` | 看过 / 想看 / 在看 | 主演 / 导演 / 编剧 | ✅ |
| `book.douban.com` | `/people/<ID>/collect·wish·do` | 读过 / 想读 / 在读 | 作者 | ❌ 站点不渲染 |

> 调研结论：Greasy Fork 与 GitHub 上**没有人做过**收藏页的字段级页内搜索。最接近的「豆瓣观影/豆列-年代筛选」（greasyfork 556815）只做电影、只有年代、只作用于当前页；各类导出脚本（bambooooo 420999 等）能拿到全量字段但需导出后自己筛。本脚本把「全量抓取建索引」和「页面内即时检索」合并到一个油猴脚本里。

## 安装

1. 浏览器安装 [Tampermonkey](https://www.tampermonkey.net/)（Chrome / Edge / Firefox / Safari 均可）；
2. 新建脚本，把 `douban-collect-advanced-search.user.js` 全文粘贴进去保存；
3. 打开任意收藏页，例如 `https://movie.douban.com/people/<你的ID>/collect`，右侧栏顶部会出现「高级搜索 · 看过」面板。

## 使用

1. 首次点 **建立 / 重建全量索引**：脚本以 1.5–2.6 秒/页的限速抓完全部收藏页（进度实时显示），索引存在浏览器本地，按 `站点 + 用户ID + 状态` 分开存，音乐站的三个状态互不干扰。
2. 之后搜索是毫秒级。索引超过 12 小时会自动后台增量更新（最多翻 8 页，遇到无新条目即停）。

### 检索维度

| 维度 | 说明 |
|---|---|
| 作品名 | 空格分隔多关键词 = 同时满足；大小写不敏感；斜杠两侧空白自动归一（`AC/DC` 能匹配到 `AC / DC`） |
| 表演者 / 作者 / 主演导演编剧 | 子串匹配，见下方「站点差异」 |
| 年份 | 起止闭区间；可勾选「包含年份未知」 |
| 标签 | 逗号/空格分隔，**精确匹配**；默认全部命中（AND），可切 OR；输入框有自动补全（从你的索引统计的标签）。**读书站无此功能**（豆瓣不渲染书本标签） |
| 我的评分 | 最低–最高（★–★★★★★）；「最低」里可选「只看未评分」 |
| 标记日期 | 起止日期，原生日期选择器 |
| 组合 | 任意叠加 |

结果在侧栏面板列出：标题（点击跳条目页）、表演者·年份·评分·标记日期、标签 chips（点一下即加入筛选）；支持**导出 CSV**。

## 站点差异（为什么不能一套解析写死）

三个站的条目 `.intro` 结构完全不同，脚本按站点分别解析：

```
music  表演者 / 发行日期 / 类型 / 介质 / 风格                     分段干净 → 直接切
book   作者 / 出版社 / 出版日期 / 价格                            分段干净 → 直接切
movie  上映日期 / 主演… / 国家 / 官网 / 导演 / 片长 / 原名 / 类型 / 编剧 / 语言
       ↑ 整行拍平，且「导演」位置不固定（有时在片长前、有时在类型后）
```

所以电影站不做「切出导演」，而是对**整条影片信息行做全文匹配**——搜「诺兰」能同时命中他当导演和编剧的作品。

其他字段来源（实测）：

- 作品名：`.title a`
- 演员/作者/导演：电影取「开头连续上映日期段之后」的 3 段作预览，整行信息留作匹配
- 年份：电影取首段上映年份；音乐/读书在各自前几段内找带 4 位年份的段
- 用户标签：`.grid-date .tags` → `标签: ...`
- 我的评分：`.date` 内 `rating{N}-t` 的 class → 1–5
- 标记日期：`.date` 内的 `YYYY-MM-DD`

> 标签只在 **list 模式**渲染，grid 模式没有 `.tags`，所以抓取强制 `?mode=list`。部分条目 `.intro` 不完整或缺失，年份会缺，标注为「年份未知」、不联网补抓。

## 隐私与安全

- **数据不出本地**：索引存于 Tampermonkey 本地存储（`GM_setValue`），搜索全部在浏览器内完成。
- **外发请求仅限三个豆瓣域名**：`@connect music.douban.com` / `movie.douban.com` / `book.douban.com`，仅抓取你自己的收藏页（登录态同源请求）；无任何第三方域名、无统计埋点。
- **无凭据**：不需要 API Key / Token / Cookie 手动配置。
- **无硬编码身份**：用户 ID 与状态在运行时从 URL 派生，存储键随之生成，脚本里不含任何个人标识。
- 全部面向用户的 innerHTML 输出均经 `esc()` 转义，防注入。

## 已知限制

- 建索引期间不要关闭页面；中断不损坏已有索引，下次增量续上。
- 限速已压到很保守；若遇 403，脚本安全中断并提示，已抓部分保留。
- 读书站收藏页没有用户标签，故该站不提供标签筛选。
- 豆瓣若改版收藏页 DOM 结构，`parseList` 与各站 `parse*` 的选择器需同步更新。

## 技术栈

纯原生 JavaScript，零依赖，`@grant` 仅用 `GM_xmlhttpRequest` / `GM_setValue` / `GM_getValue` / `GM_deleteValue` / `GM_addStyle`。
